# Contributing as a Translator

GeoGuess is an open-source project that welcomes contributions from translators around the world. If you'd like to help make GeoGuess available in more languages or improve existing translations, you can contribute through our Crowdin project.

## How to Contribute

1. Visit our translation platform: [http://translate.geoguess.games/](http://translate.geoguess.games/)
2. Create a free Crowdin account or sign in with your existing account
3. Select the language you want to translate to
4. Start translating! You can suggest new translations or vote on existing ones

If your language is not available, you can request to add it by contacting the project maintainers on the Crowdin platform.

## Why Contribute?

- Help make GeoGuess accessible to players worldwide
- Improve the quality of translations in your language
- Join a community of contributors
- Your contributions will be credited in the project

## Questions?

For more information about the translation process, please refer to the [official Crowdin guide for translators](https://support.crowdin.com/for-translators/).

Thank you for helping make GeoGuess better for everyone! 🌍
